## Research and three shipped features

Eight S/M ideas were compared against sourced competitor capabilities and public complaints. Do not claim competitors lack itemization, cash or offline splitting: Splitwise, Tricount, Splid and Settle Up already cover many of these. Our opportunity is understandable Hinglish input plus voice control and explicit review. Complaints are anecdotes, often dated or from competing developers, not representative statistics. Full sources and all eight decisions: [RESEARCH.md](RESEARCH.md).

The three additions are: group-bound reload recovery of unsaved review; an explained, optional next-payer suggestion; and a spoken briefing that checks fresh balances and stops the mic before audio. No new dependency or LLM endpoint was required. See research for implementation/test evidence.

## Manual checks and known limits

- Actual microphone recognition, OS speaker quality, live Claude, outbound WhatsApp/UPI and hosted deployment need human/account checks. Browser QA injected recognition and intercepted synthesis, not real audio-quality validation.
- To use real Claude: set the server key/model, USE_CLAUDE_STUB=false, restart API. Keep true for the keyless demo.
- No auth: anyone with API access can edit the public group; use demo information. Seed UPI IDs are unverified.
- Local checkpoints contain names/raw text, expire after seven days and are last-writer-wins. Blocked/cleared storage can lose them. They recover parsed review, not an unparsed textarea or offline server parsing. Save/discard clears them; discard on shared devices.
- Exact minimum payments are guaranteed up to 16 nonzero balances. Above that is a bounded greedy fallback. Wrapped caption cache remains process-local and resets on restart.
- Optional vision, a scheduler, secure approval/share links and trip groups were deferred for documented risks. No identity/payment verification was faked.
- Original Lovable history is unavailable; the audit uses the earliest accessible local snapshot. No pushed history was rewritten and no cloud deployment/push was performed.
